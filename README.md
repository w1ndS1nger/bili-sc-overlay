# B站直播醒目留言叠加层

Chrome / Edge 扩展。在 `live.bilibili.com/房间号` 直播间里，进入浏览器全屏、网页全屏或 B 站站内悬浮播放器后，会在画面右上角显示当前有效的醒目留言（SC）。多个留言纵向排列，可以滚动；每条留言在服务端给出的 `end_time` 到达时自动消失。普通页面播放时不叠加。

卡片显示留言者头像、头像框（如果有）、昵称、金额和内容；优先采用 B 站给每条留言返回的卡片颜色，缺少颜色字段时采用同档位默认配色（1000 元为红色）。

按住任意卡片的顶部信息栏，即可拖动整组留言；拖动位置限制在播放器画面内，多条留言时仍可在卡片列表里滚动。位置在当前标签页内按房间和播放模式分别记忆，刷新页面后恢复右上角默认位置。

点击浏览器工具栏中的扩展图标，可设置最多显示的留言条数（1、2、3、5、10 或全部）、窗口宽度、最大高度和透明度，改动会自动保存并应用到已打开的直播间。全屏时也可拖动卡片组**左下角的蓝色把手**调整宽度和最大高度；被条数限制隐藏的有效留言会显示数量提示。

## 安装

1. 解压 ZIP。
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后的 `bili-sc-overlay` 文件夹。
4. 打开或刷新 B 站直播间，进入网页全屏、全屏或站内悬浮播放器。

进入画面时立即请求一次，随后每 6 秒同步新留言，到期检查每 0.5 秒进行一次。留言由 B 站接口提供；若接口暂时失败，已显示的留言仍按原定时间移除。

## 范围

- 支持 B 站**网页内**的悬浮播放器；浏览器原生「画中画」是独立视频窗口，普通网页扩展无法往该窗口加 HTML 叠加层。
- 如果网站让 `<video>` 元素本身进入浏览器原生全屏，浏览器也不允许把 HTML 放进该视频元素；B 站以播放器容器进入的全屏可用。
- 使用非官方公开接口。B 站修改接口或播放器结构后可能需要更新扩展。当前版本不要求登录，不读取 Cookie，不包含第三方依赖。

开发验证：在目录中运行 `node --test tests/sc-data.test.js`。API 字段资料见 [SC 列表](https://github.com/dd-center/BiliSC-WebAPI-Doc) 和 [直播间初始化接口](https://github.com/pskdje/bilibili-API-collect/blob/main/docs/live/info.md)。
